# 기획서 보완 결정

- 결정일: 2026-11-27
- 결정자: 최준환
- 기준 문서: [기획서.md](../기획서.md) (원문은 바꾸지 않고, 이 문서로 보완함)

## 결정 사항

| 번호 | 상황 | 처리 |
|---|---|---|
| 1 | 소비기한만 맞고 품명 핵심어가 하나도 겹치지 않음 | 성적서 없음으로 빼고 특이사항으로 알림 |
| 2 | 같은 품목·같은 소비기한 성적서가 여러 개 | 제조일자가 빠른 것 사용 |
| 3 | 성적서 폴더 안에 하위 폴더가 있음 | **작업 중지** + 알림 |
| 4 | 피킹리스트 양식 | 틀은 고정, 값(출하일자·품명·품번·수량·소비기한 등)만 바뀜. 사용자가 준 견본 기준으로 읽음 |
| 5 | 피킹리스트 BOX 칸이 비었거나 0 | **작업 중지** + 알림 |
| 6 | 성적서 수량 칸 숫자가 10이 아니거나, `Box`가 여러 번 나와 수량 칸이 애매함 | **작업 중지** + 알림 |
| 7 | 성적서와 같은 글꼴을 쓸 수 없음 | 비슷한 글꼴로 쓰고 알림 |
| 8 | 성적서가 2페이지 이상 | 모든 페이지를 넣고 알림 |
| 9 | 넣을 성적서가 하나도 없음 | PDF를 만들지 않고 팝업만 띄움 |
| 10 | 여는 방식 | 웹 주소로 엶 (예: GitHub Pages) |
| 11 | 실제 성적서 파일 | 테스트용으로만 쓰고, 코드·레포에는 넣지 않음 |

## 주의

- 3·5·6번은 기획서 7장 "모든 예외는 처리를 멈추지 않음" 원칙의 **예외**임. 이 세 경우에는 작업을 멈춤.
