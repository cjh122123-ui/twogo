# twogo

투썸 출고 피킹리스트 PDF와 성적서 폴더를 넣으면, 품목별 성적서를 찾아 박스 수량을 고치고 PDF 하나로 합쳐 주는 웹 페이지입니다. 모든 처리는 브라우저 안에서만 합니다.

- 상태: 첫 버전 (견본 피킹리스트·성적서로 테스트함)

## 쓰는 법

1. 웹 주소를 엽니다.
2. 피킹리스트 PDF와 투썸 성적서 폴더를 고릅니다.
3. "성적서 PDF 만들기"를 누르면 `YYMMDD 투썸 (상온제품).pdf` 같은 파일이 내려받아지고, 특이사항 팝업과 결과표가 나옵니다.

## 구성

- 정적 웹 페이지라 빌드가 필요 없습니다 (`index.html`, `css/`, `js/`). Vercel·GitHub Pages 어디든 그대로 올리면 됩니다.
- `js/logic.js`: 피킹리스트 읽기, 성적서 짝짓기, 순서, 수량 칸 찾기
- `js/app.js`: 화면, PDF 읽기·합치기, 수량 덮어쓰기
- PDF 도구: [pdf.js](https://github.com/mozilla/pdf.js) 4.10.38, [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1을 jsDelivr CDN에서 불러옴 (도구 코드만 받아 오고, 고른 파일은 밖으로 보내지 않음)
- 수량 숫자는 성적서에 들어 있는 글꼴에 필요한 숫자가 모두 있으면 그 글꼴로 쓰고, 없으면 비슷한 글꼴(Helvetica)로 쓰고 알립니다.
- 기획서: [기획서.md](기획서.md)
- 기획서 보완 결정: [docs/기획서_보완결정.md](docs/기획서_보완결정.md)

실제 성적서·회사 데이터와 API 키는 이 레포에 넣지 않습니다.
